# Secure File Transfer Simulator

## 📌 Project Overview

**Secure File Transfer Simulator** is a Python-based mini project developed to compare the security features of FTP, SFTP, and SCP. It provides a graphical user interface (GUI) using Tkinter to demonstrate file transfer, protocol comparison, security analysis, and a real-world cybersecurity case study.

The project helps users understand why secure file transfer protocols are important for protecting sensitive information.

## 🎯 Objectives

* Understand the differences between FTP, SFTP, and SCP.
* Compare encryption and security features of different protocols.
* Demonstrate file transfer through a graphical interface.
* Display security analysis and comparison results.
* Study the MOVEit Transfer security incident of 2023.

## ✨ Features

* **File Selection:** Select a file from your computer.
* **File Transfer Simulation:** Copy a selected file into the local `received` folder.
* **Protocol Selection:** Choose FTP, SFTP, or SCP.
* **Security Comparison:** Compare encryption, authentication, and security levels.
* **Security Analysis:** View protocol security scores and recommendations.
* **MOVEit Case Study:** Learn about the 2023 MOVEit Transfer vulnerability.
* **Results Dashboard:** View the final comparison of all three protocols.
* **Visual Transfer Simulation:** Observe an animated file-transfer process.
* **Transfer History:** View transfer details and status.
* **User-Friendly GUI:** Interactive interface built using Python Tkinter.

## 🔐 Protocol Comparison

| Feature                        | FTP                              | SFTP                          | SCP                           |
| ------------------------------ | -------------------------------- | ----------------------------- | ----------------------------- |
| Full Form                      | File Transfer Protocol           | SSH File Transfer Protocol    | Secure Copy Protocol          |
| Encryption by Default          | No                               | Yes, through SSH              | Yes, through SSH              |
| Security Level                 | Low by default                   | High when properly configured | High when properly configured |
| Recommended for Sensitive Data | No, unless appropriately secured | Yes                           | Yes                           |

## ▶️ How to Run the Project

1. Clone or download this repository from GitHub.

2. Open the project folder in Visual Studio Code.

3. Open the terminal in the project folder.

4. Run the following command:

   ```bash
   python main.py
   ```

5. Select a file using the **Browse** button.

6. Choose FTP, SFTP, or SCP.

7. Use the available options to explore the security comparison, analysis, case study, results dashboard, and visual simulation.

## ⚠️ Important Note

This project is an **educational local simulation**. File transfers are performed by copying files locally using Python; the application does not establish actual FTP, SFTP, or SCP network connections. The animated transfer is illustrative and does not represent real network packets.

The security scores displayed by the application are illustrative academic ratings, not official industry-standard scores.

The MOVEit Transfer 2023 incident is included as a case study to demonstrate the importance of securing file-transfer systems. MOVEit Transfer is a managed file-transfer product, not itself an FTP, SFTP, or SCP protocol.
